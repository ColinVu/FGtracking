# frontend-mobile (Expo React Native) — PrizePicks-styled Minigame

Small Expo React Native app that provides a pixel-goalpost minigame UI.  
Main source: [`App`](frontend-mobile/App.js) which contains the UI, [`PixelScene`](frontend-mobile/App.js) and the tiny countdown hook [`useCountdown`](frontend-mobile/App.js).

Files
- [`App.js`](frontend-mobile/App.js) — main app component and UI
- [`index.js`](frontend-mobile/index.js) — Expo entry point
- [`package.json`](frontend-mobile/package.json) — npm scripts & dependencies
- [`app.json`](frontend-mobile/app.json) — Expo app config
- [`assets/`](frontend-mobile/assets) — icons and images

Prerequisites
- Node.js (14+ recommended)
- npm or yarn
- Expo CLI (optional) — you can use the bundled `npx expo` commands

Quick start (recommended)
1. Install dependencies
```sh
npm install
# or
yarn
